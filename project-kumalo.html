My role

I contributed to Kumalo, a full-stack web application developed with KumaloTech, as an invited collaborator. The repository is private, so this write-up focuses on the type of work and what I learned rather than internal details.

What I worked with

  • Next.js frontend. I worked within an existing frontend structure and followed patterns already used in the project.
  • Node.js API layer. I gained exposure to how frontend features connect to backend routes and application logic.
  • Team codebase practices. The experience involved reading existing code, understanding conventions, and making changes that fit the project.

What I learned

Working in a shared codebase helped me appreciate how much software development depends on consistency, communication, and understanding decisions made before you join a project. It also gave me useful exposure to a modern JavaScript stack.
