Project 06 · Academic · Group

SmartFix IT Solutions

A computer-repair booking website — I built the database connection and user registration module.

PHP · MySQL · JavaScript

The project

A group build of a booking site for a computer-repair business: customers register, describe their device problem, and book a repair slot.

My contribution

  • Database connection layer — the shared PHP/MySQL access the rest of the team built on.
  • User registration module — form validation, duplicate-account handling, and secure credential storage.
  • Presented our module's design and decisions to the class.

What it taught me

This was my first time building authentication-adjacent code for other people to depend on. Designing an interface my teammates could consume without breaking — and documenting it well enough that they could — turned out to be the real lesson.
